# 실감미디어 진로 선택 대시보드

VR·AR·XR·메타버스 등 **실감미디어 분야의 진로를 탐색하는 학생**을 위한 한 페이지 대시보드입니다.
적성 자가 진단으로 나에게 맞는 트랙(기획·디자인 / 개발·공학)을 찾고, 직업 → 전공 → 대학·진로검사 순서로 진로를 좁혀 볼 수 있습니다.

## 주요 기능

| 탭 | 내용 |
|---|---|
| ① 적성 진단 | 11개 항목 체크리스트(공통 / 기획·디자인 / 개발·공학) → 트랙별 적합도 막대와 추천 트랙 |
| ② 직업 탐색 | 실감미디어 직업 12개 카드(하는 일, 핵심 역량, 주요 도구, 관련 전공, 흥미 유형), 트랙 필터, 연간 임금 범위·재직자 학력 분포 차트 |
| ③ 전공·대학 | 관련 전공 지도(학과 12개), 첨단분야 혁신융합대학(실감미디어) 7개 대학과 대학별 역할 |
| ④ 검사·로드맵 | 커리어넷·고용24 공식 진로검사 안내와 해석 팁, 중학교~졸업 후 단계별 로드맵 |

- 적성 체크 결과에서 **"추천 트랙 직업 보기"** 를 누르면 해당 트랙 직업만 바로 볼 수 있습니다.
- 체크 결과는 브라우저 화면에서만 계산되며 **어디에도 저장·전송되지 않습니다.**
- PC·모바일 반응형, 기기 설정에 따른 다크 모드를 지원합니다.
- 주소 끝에 `#aptitude`, `#jobs`, `#majors`, `#path`를 붙이면 해당 탭이 바로 열립니다.

## 사용 방법

### 바로 열기
`index.html` 파일을 내려받아 브라우저로 열면 됩니다. 별도 설치나 서버가 필요 없습니다.

### GitHub Pages로 배포
1. 이 저장소의 루트에 `index.html`이 있는지 확인합니다.
2. 저장소 **Settings → Pages** 로 이동합니다.
3. **Source** 를 `Deploy from a branch`로, 브랜치를 `main` / `(root)`로 선택하고 저장합니다.
4. 잠시 후 `https://<사용자명>.github.io/<저장소명>/` 에서 확인할 수 있습니다.

## 파일 구성

```
├── index.html   # 대시보드(HTML·CSS·JavaScript·데이터가 모두 들어 있는 단일 파일)
└── README.md
```

외부 라이브러리 없이 순수 HTML/CSS/JavaScript로 작성했습니다. 글꼴([Pretendard](https://github.com/orioncactus/pretendard))만 CDN에서 불러오며, 연결되지 않으면 기본 한글 글꼴로 표시됩니다.

## 데이터 수정하기

모든 데이터는 `index.html` 하단 `<script>` 안의 `const DATA = {...}` 객체에 있습니다.

| 키 | 내용 |
|---|---|
| `checklist` | 적성 체크 항목 (`track`: 공통 / 기획·디자인 / 개발·공학) |
| `jobs` | 직업 카드 (`track`: 기획·디자인 / 개발·공학 / 융합) |
| `job_stats` | 직업별 임금(만원, 하위25%·중위·상위25%), 만족도, 일자리 전망 |
| `edu_dist` | 직업별 재직자 학력 분포(%) |
| `majors` | 관련 전공 지도 |
| `consortium` | 혁신융합대학 참여 대학과 역할 |
| `tests` | 공식 진로검사 안내 |
| `roadmap` | 단계별 진로 로드맵 |

항목을 추가·수정하면 카드, 표, 상단 숫자가 자동으로 반영됩니다.
